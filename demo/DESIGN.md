# 万事屋个人门户 · UI/UX 设计规范

> 本目录是**生产前端**：原生 HTML/CSS/JS，无打包器。服务端组装 `views/*.html` 写入壳层，静态 URL 的 `?v=` 由 `app_version.VERSION` 注入。
> 入口为 ESM `js/boot.js`；主视图走 hash 路由（`#/notes`）。不引入 Vue/React。

│  侧边栏    │  [折叠] 页面标题    [全局搜索 ⌘K]   [🌓][🔔][👤] │

│          │                                            │
│  · 总览    │         内容区 Content (max 1400px)         │
│  · 功能模块 │         12 列响应式网格 (.grid12)            │

└──────────┴────────────────────────────────────────────┘

- **侧边栏**：分组导航（总览 / 功能模块 / 偏好），当前项有主色高亮条 + 浅色底；底部固定用户卡片（头像、姓名、在线状态）。可折叠为 76px 图标栏。
- **顶栏**：左侧折叠按钮 + 当前页面标题 + 日期；中央为**全局搜索**（占位提示、⌘K 快捷键、聚焦弹出引擎选择面板）；右侧为明暗切换、通知（红点）、用户头像下拉菜单。顶栏使用 `backdrop-filter: blur` 毛玻璃，滚动时内容从下方穿过。
- **内容区**：12 列网格，间距 20px。仪表盘采用「4+8 / 4+8 / 4+4+4」的错落节奏，保证信息密度与留白平衡。

## 二、核心组件设计（含状态）

### 通用卡片 `.card`
- 结构：`card-head`（图标+标题+状态 chip+更多链接）/ `card-pad`（内容）。
- 状态：默认（表面色 + 1px 边框 + 轻阴影）→ 悬停（`.lift` 上浮 2px、阴影加深、边框提亮，160ms 缓动）→ 加载（骨架屏 `.sk` + 微光扫过动画）→ 空态（`.empty`：虚线圆图标 + 标题 + 说明 + 行动按钮）。

### 天气卡片
- 大号细体温度（52px / weight 250）营造轻盈感；天气图标带主色投影。
- 湿度/风/空气三个次级指标用浅底小方块；未来 4 天预报横向排列，"今天"用主色浅底高亮；悬停每天卡片轻微浮起。

### 系统监控
- 环形仪表：SVG `stroke-dasharray` 驱动，按阈值着色（<50 绿 / <80 琥珀 / ≥80 玫红），数值变化时 0.8s 缓动过渡。
- 容器表格：行悬停浅底并**渐显操作按钮**（重启/停止/日志），状态用带圆点的语义色胶囊（运行中·绿 / 重启中·琥珀 / 已停止·玫红）。
- 网络图表：纯 SVG 面积图 + 渐变填充 + 虚线网格线，上线时替换为 ECharts/µPlot 即可复用容器样式。

### 每日单词
- 单词 30px 粗体 + 音标（等宽字体）+ 词性胶囊；例句用主色左边线引用块；操作：发音 / 加入生词本 / 换一个。

### 快捷导航
- 书签磁贴：彩色字母 favicon（色相用 `--fav` 变量，可自定义）+ 名称 + 域名；悬停上浮、渐显拖拽手柄（`.grip`），暗示可拖拽排序。
- 分类用分段式 Tabs；"添加新书签"为虚线占位磁贴，悬停变主色。

### 密码保险库（安全感表达）
- **锁定态**：内容整体 `blur(7px)` 遮蔽且不可交互，中央锁卡片（盾牌图标 + 主密码输入 + 冻结策略提示 + "零知识架构"说明）。
- **解锁态**：凭据行 = 站点图标 + 账号 + 强度条（4 段语义色）+ 掩码密码 + 更新时间 + 操作（显示/复制/更多）。
- 顶部常驻绿色安全横幅（AES-256-GCM · 无异常访问），以克制的绿色传达"受保护"而非恐吓式的红色。

### 灵感速记
- 编辑器顶栏：加粗/斜体/标题/列表/代码/链接/图片按钮 + 右侧「编辑 · 分屏 · 预览」分段控件。
- 分屏：左等宽源码（`textarea`）、右渲染预览（标题/代码块/引用/列表均按 Markdown 排版）。
- 底栏：字数 · 自动保存状态 · 标签胶囊。

### 实用工具箱
- 翻译：语言选择 + 交换按钮 + 双栏面板（结果栏用主色浅底区分）+ 复制/朗读。
- 密码生成：等宽大字结果框 + 强度条 + 长度滑杆 + 字符集复选 + 一键重新生成。
- 小工具磁贴：图标浅底方块 + 名称 + 一句话描述；未上线工具半透明 + "即将上线"角标。

### 全局搜索
- 顶栏胶囊输入框，聚焦时 4px 主色光环；下拉面板分三区：**引擎切换**（Google/Bing/DuckDuckGo/百度/站内检索 chips）、**最近搜索**、底部快捷键提示。回车跳转所选引擎，实现时可直接拼 URL。

## 三、配色与视觉规范

### 3.1 默认配色（靛蓝主题）

| 角色 | 深色模式 | 浅色模式 |
|---|---|---|
| 主色 `--om-primary` | `hsl(243 72% 60%)` | `hsl(243 72% 54%)` |
| 页面底 `--om-bg` | `#0c0f15` | `#f3f5fa` |
| 卡片面 `--om-surface` | `#141824` | `#ffffff` |
| 次级面 `-2 / -3` | `#1a2030 / #232b3e` | `#f3f5fb / #e9edf6` |
| 描边 `--om-border` | `rgba(255,255,255,.07)` | `#e4e8f1` |
| 文字 1/2/3 级 | `#edf0f7 / #9aa3b8 / #5f6880` | `#171c2b / #5c6579 / #9aa2b5` |
| 成功 / 警告 / 危险 / 信息 | `#10b981 / #f59e0b / #f43f5e / #38bdf8` | 同 |

### 3.2 其他规范
- **圆角**：控件 10px · 卡片 18px · 胶囊 999px。
- **阴影**：三级（静态轻阴影 / 悬停中阴影 / 弹层重阴影），深色模式加深、浅色模式偏冷灰。
- **字体**：系统字体栈（PingFang SC 优先）；数字启用 `tabular-nums`；代码/密码用等宽字体。
- **动效**：快反馈 160ms、模式切换 280ms，统一 `cubic-bezier(.4,0,.2,1)`；尊重 `prefers-reduced-motion`。

### 3.3 用户自定义主题的实现机制

```css
:root{
  --om-hue: 243;                /* ← 用户唯一需要改的值 */
  --om-sat: 72%;
  --om-primary: hsl(var(--om-hue) var(--om-sat) 60%);
  /* 派生色全部自动生成 */
  --om-primary-ghost: color-mix(in oklab, var(--om-primary) 14%, transparent);
  --om-primary-soft:  color-mix(in oklab, var(--om-primary) 16%, var(--om-surface));
}
```

三个关键设计决策：
1. **主色拆为 HSL 通道**：换肤只需 `setProperty('--om-hue', 190)` 一行 JS，按钮、导航高亮、图表、焦点环全站联动。
2. **派生色用 `color-mix()`**：浅底色、半透明高亮、描边均按当前模式自动计算，避免为每个主色 × 每个明暗模式手写色板。
3. **明暗与主色正交**：`data-theme="light|dark"` 只切换表面色与文字色，主色体系独立，两维度可任意组合。

内置预设：靛蓝 243 / 青碧 190 / 翡翠 160 / 琥珀 35 / 玫瑰 340，另提供取色器（HEX → HSL 转换后回写）。

## 四、多用户与个性化交互流程

### 4.1 用户切换流程
```
点击侧边栏用户卡片 或 头像菜单「切换用户」
  → 弹出用户列表（头像 / 姓名 / 角色说明，访客标注权限范围）
  → 选中目标用户 + 输入其密码或 PIN
  → 「验证并切换」→ 整站重载该用户空间（仪表盘布局、书签、笔记、主题偏好全部独立）
```
要点：切换前必须二次验证；每个用户卡片用不同渐变色头像强化"身份感"。

### 4.2 主题设置流程
```
头像菜单「主题与外观」或侧边栏「外观设置」
  → 右侧抽屉滑出：
     ① 模式分段控件（浅色 / 深色 / 跟随系统）——即时预览
     ② 主色色板 5 预设 + 自定义取色器——即时预览
     ③ 布局偏好开关（紧凑密度 / 卡片显隐 / 降低动效）
  → 「保存配置」→ Toast 确认 → 写入该用户的偏好文件
```
所有改动即时生效、保存才持久化；"恢复默认"提供安全回退。

### 4.3 偏好持久化建议（实现阶段）
- 每用户一份 `prefs.json`：`{ theme: {mode, hue, sat}, layout: {compact, hiddenCards}, bookmarks: [...] }`。
- 登录后先拉取偏好 → 给 `<html>` 写入 `data-theme` 与 `--om-hue`，避免首屏闪白（可在服务端注入）。

## 七、v3 功能实现记录（UI Demo → 可运行应用）

### 7.1 技术选型（最终落地）
- **前端**：本目录即生产 UI。原生 ESM（`js/boot.js`），无打包器；主视图 hash 路由（`#/notes`）；`?v=` 由 `app_version.VERSION` 注入。第三方库 vendored 在 `js/vendor/`（marked / DOMPurify / qrcodejs）。
- **后端**：FastAPI（Python 3.11）：`backend/main.py` 应用工厂 + `backend/routers/` 按域拆分 + `sessions.py`（SQLite 会话）+ `storage.py`（三引擎，内部 `store/`）。
- **持久化**：默认文件引擎，可切 SQLite / MySQL / PostgreSQL 并自动迁移。全局账号仍在 `data/config.json`；登录会话在 `data/sessions.sqlite`。
- **认证**：PBKDF2-SHA256 口令哈希 + SQLite 会话（7 天滑动续期）+ Bearer token；Obsidian 用 `X-API-Key`。首个注册用户为管理员。

### 7.2 关键设计决策
- **密码保险库零知识加密**：主密码经 PBKDF2（31 万次）派生密钥，AES-256-GCM 在浏览器端加密全部凭据；服务端仅存盐值与校验串，无法解密。
- **偏好即生效、保存才持久化**：设置中心改动先写 `localStorage` 预览，「保存更改」才 `PUT /api/settings`。
- **Docker 监控降级**：宿主机未挂 `docker.sock` 时前端展示提示而非报错。

### 7.3 部署（NAS Docker）
```bash
docker compose up -d --build   # 端口 8000，数据卷 ./data → /app/data
```
`docker-compose.yml` **默认不**挂载 `docker.sock`（需要容器监控时取消注释）；时区 `Asia/Shanghai`。公网 HTTPS 见 `docker-compose.tls.yml`。本地开发 `pip install -r requirements.lock.txt && python3 backend/main.py`。
