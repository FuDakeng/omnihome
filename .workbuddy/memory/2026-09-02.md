## v0.2.14：实时渲染链接/表格 + 灯箱交互 + 大纲右侧栏 + 冻结

### Bug 1：加粗部分生效 + 标题多出两行符号（live 模式）
- 根因：LiveMD.insertRawAt 对**无换行**的单行文本会拆成两行——`newLines = [cur+parts[0]].concat(parts.slice(1,-1), [parts[last]+cur])` 里 parts[0]==parts[last]（单行时）重复使用 → `'# '` 插入变两行 `'# '` + `'# 原内容'`
- 修：text 无 \n 时直接 `arr[li] = cur.slice(0,local) + text + cur.slice(local)`

### Bug 2/3：表格/链接实时不渲染
- LiveMD.inlineHtml 只有图片/代码/强调，无链接、无块级表格
- 修：inlineHtml 加 `[text](url)`（a 标签 data-pre 存 `[text](url)`、data-post=""，文本可编辑、序列化无损）与 `<url>` 自动链接
- rebuild 加**表格块**：`isTableRow + isTableSep` 检测，renderTable 渲染 `.lm-table`（contenteditable=false + data-table-raw 存原文），工具条 +行/+列/-行/-列，数据行 draggable 拖拽调序，tableMutate 改后重建
- 序列化：lineRaw / rawOfNode 对 data-table-raw 直接返回原文；restoreInLine/pointAtRaw 跳过表格块（光标放块后）
- 坑：isTableSep 原正则只允许一段 `-`，分隔行 `| --- | --- |` 匹配失败 → 改为"去首尾 | 后剩余只由 [\s:| -] 组成且至少一个 -"
- 坑：rebuild 收集表格时漏掉分隔行（只收表头+数据行）→ cells[1] 变成数据行 → tbody 空 → 补 `rows=[line, sep]`

### Bug 5：灯箱关闭/删除无响应
- 根因：`#assetLightbox` 在页面底部（1736 行）晚于 notes.js（1731）执行 → init 时元素不存在 → `$('#assetLightbox')?.addEventListener` 短路永不生效；而树委托 #noteTree 在其之前存在所以正常
- 修：改为 document 委托（`if (!e.target.closest('#assetLightbox')) return;`）+ 背景点击关闭（mask 有 data-asset-close）+ 删除用 confirmModal
- **通用教训：对页面底部的元素绑定事件，务必 document 委托，别信 `?.`**
