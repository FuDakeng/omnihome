# OmniHome 快捷导航 · 浏览器扩展

连接你的 OmniHome（万事屋）服务器：右键快速收藏网页、浏览器书签与万事屋双向同步（含分类与顺序）。适用于 Chrome / Edge（Manifest V3）。

## 安装

1. 解压 `omnihome-extension.zip` 到一个固定文件夹（不要放在会被清理的目录）。
2. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）。
3. 开启右上角「开发者模式」。
4. 点击「加载已解压的扩展程序」，选中解压后的文件夹。
5. 点击浏览器右上角插件图标，填写服务器地址（如 `192.168.1.10:8000`）、账号、密码。
   - 「测试连接」：仅验证地址可达且是 OmniHome 服务，不验证账号。
   - 「登录」：验证账号并保存凭证（仅存于本机浏览器）。

> 也可在万事屋「设置 → 功能设置 → 浏览器扩展」直接下载安装包（需部署包根目录附带 `omnihome-extension.zip`）。

## 功能

### 收藏网页
- **右键菜单**：页面右键 → 「收进 OmniHome 快捷导航」→ 选择分类或「选择分类并保存…」。
- 保存在**当前页面内的浮层卡片**完成：可改名称、选分类、AI 分析（自动推荐分类、生成描述与标签）、保存。不再新开标签页。
- 插件弹窗内也可「收藏到常用」或展开「选择分类」保存。
- AI 分析需先在万事屋「设置 → AI 智能」中配置并启用，否则卡片内会给出相应提示。

### 书签同步（万事屋 → 浏览器）
- 同步目标是**浏览器书签栏整体**：书签栏会被清空并完全镜像万事屋的内容——分类对应文件夹，书签顺序与万事屋一致，确保两端看到的内容完全一致。
- **登录后不会自动同步**。首次点击「立即同步」时会弹窗警告，点击确定后**自动下载一份当前浏览器书签备份**（Netscape HTML，浏览器书签管理器可直接导入回滚），然后执行同步。
- 之后万事屋有变化会自动同步，触发方式：
  - 定时轮询（默认 30 分钟，可选 5 分钟 ~ 24 小时）；
  - 在万事屋页面新增 / 修改 / 删除书签或分类后即时触发（内容脚本探测写请求）；
  - 打开插件弹窗时静默比对。
- 设置中可开启「不同步隐藏的分类」：万事屋中被隐藏的分类不会出现在浏览器书签栏。
- 万事屋中地址为空或非网页的书签会被跳过（同步状态中显示跳过数量），不会中断整个同步。

### 反向导入（浏览器 → 万事屋）
- 弹窗「导入浏览器书签」：清空万事屋现有书签与自定义分类，将浏览器书签栏整体导入（文件夹转为分类，散落书签进「常用」）。
- 执行前服务端会自动备份一份当前数据，可在万事屋「设置 → 数据与存储」恢复。

## 常见问题

- **Invalid URL**：旧版问题（单条非法书签中断同步）。新版已过滤非法地址并跳过，不再中断。
- **收藏后分类不对**：请确认万事屋服务端为最新版本；扩展保存时会显式携带分类并回显实际落库分类。
- **登录后插件仍显示登录页**：旧版问题（同步阻塞应答），新版登录立即应答且登录后不自动同步。
- 服务端为 HTTP 而你在 HTTPS 页面使用插件时，浏览器可能拦截混合内容；建议为服务端配置 HTTPS 或在浏览器站点设置中允许不安全内容。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `manifest.json` | MV3 清单（含内容脚本注入声明） |
| `background.js` | 后台：右键菜单、同步引擎、备份/导入、消息路由 |
| `content.js` | 内容脚本：页内保存卡片 + 变动信号转发 |
| `content-hook.js` | MAIN world：钩住页面 fetch 探测万事屋数据变动 |
| `api.js` | 服务端 API 封装（401 自动重登） |
| `popup.*` | 插件弹窗界面 |
