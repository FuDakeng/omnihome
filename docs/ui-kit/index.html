Overview

可迁移的界面规范

令牌、组件与断点来自当前产品界面，类名与数值和《通用UI规范》一致。拉宽或拉窄窗口即可看到桌面侧栏、图标栏和手机抽屉。

阅读说明文档 查看组件

怎么用这一页

本页自身就是应用壳的标本：顶栏 64px（紧凑 56px），侧栏 250px，窄桌面收成 76px 图标栏，768px 以下改为抽屉。没有底部标签栏。

--ui-hue 243 控件圆角 10 卡片圆角 18 成功 警告 危险

顶栏工具

月亮切换明暗，横线切换紧凑密度，波形关闭动效。手机上先点汉堡打开目录，点放大镜展开搜索。

Principles

原则

品牌色只出现在行动点和当前位置。表面靠四级灰阶分层。手机继续用侧栏，只是把它收进抽屉。

一个区域内只有一个实心主按钮。危险操作先走确认层。
不要加常驻底栏，不要用裸 100vh 当手机全屏高度，不要把主色当成健康度。

Color

色彩

点色板会改写 --ui-hue 与 --ui-sat，主按钮、焦点环和当前导航一起变。明暗由顶栏切换，语义色保持不变。
